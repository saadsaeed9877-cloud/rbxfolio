## 📋 14 Environment Variables

All documented in `.env.example` and `docs/ENV_SETUP_REFERENCE.md`:

```
1. DATABASE_URL              → from Supabase
2. BETTER_AUTH_SECRET        → generate random
3. BETTER_AUTH_URL           → your frontend URL
4. NEXT_PUBLIC_API_URL       → your API URL
5. NEXT_PUBLIC_APP_URL       → your app URL
6. PORT                      → 3001
7. UPLOAD_DIR                → ./uploads
8. CORS_ORIGIN               → your frontend URL
9. BREVO_API_KEY             → from Brevo
10. BREVO_FROM_EMAIL         → noreply@rbxfolio.tk
11. BUNNY_STORAGE_ZONE       → from Bunny
12. BUNNY_API_KEY            → from Bunny
13. BUNNY_STORAGE_ENDPOINT   → from Bunny
14. SENTRY_DSN_API           → from Sentry
    + NEW_RELIC_LICENSE_KEY, NEW_RELIC_APP_NAME, etc.
```

**All explained in docs/ENV_SETUP_REFERENCE.md**
